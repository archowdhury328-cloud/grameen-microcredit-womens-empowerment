# Data dictionary

## 1. Published aggregates: `data/published/paper_values.csv`

| Column | Meaning |
|---|---|
| `record_id` | `T4-01`.. for tables, `N-01`.. for narrative statements |
| `source_type`, `source_table`, `source_location` | table, figure or narrative; the heading or paragraph it comes from |
| `printed_page` | journal page: tables 4-6 on 2585, income narrative 2582, autonomy and community narrative 2583 |
| `group_dimension`, `group_label` | e.g. `sector` / `Small Business`; `age_group` / `30-45 years` |
| `secondary_dimension`, `secondary_label` | Table 6 only: `location` / `Rural`, `Mixed`, `Urban` |
| `measure`, `unit`, `value` | e.g. `income_increase`, `percent`, `32` |
| `change_basis` | `percent_increase` (the wording says income rose by x%), `level_percent_unspecified` (Table 6 index), `not_stated` (the paper does not say whether x% is relative or percentage points). `percentage_point_change` is allowed but never used, because the paper never states one |
| `denominator_n`, `denominator_status` | always `unavailable`: the paper reports no group size |
| `wording` | the printed column heading or a short quotation |
| `notes` | caveats, e.g. that "Overall" cannot be derived from subgroup means |

The three reported percentages that are not in a table (28% income, 35% autonomy, 40% community participation) are
rows `N-01`, `N-04` and `N-07`, each with its own page and wording. The 35% and 40% values have no table. Table 5's
over-45 value (20%) appears only in the table and Figure 3.

## 4. Row-level microdata schema (`grameen validate-data`)

One row per borrower plus a `<name>.meta.yaml` sidecar.

| Field | Type / meaning |
|---|---|
| `borrower_id` | unique pseudonymous id; no names or national ids |
| `household_id`, `psu`, `strata`, `survey_weight` | optional design fields; clusters and weights are used when present |
| `age`, `sector` | descriptive comparisons only |
| `income_baseline`, `income_followup` | income before and after the loan; same unit, period, currency |
| `loan_size`, `loan_tenure_months`, `education_level` | income predictors; education is `none/primary/secondary/higher` |
| `training_participation`, `group_membership` | autonomy predictors (0/1) |
| `autonomy` | documented as continuous, binary or ordinal |
| `community_meeting_attendance`, `leadership_role` | engagement predictors |
| `social_engagement` | independently measured; its components must be declared in the metadata |
| `is_synthetic` | required on synthetic data only |

Metadata sections: `dataset_id`, `dataset_type` (`synthetic`, `original_microdata`, `independent_bids`), `income`
(`unit_level`, `reference_period`, `currency`, `baseline_comparable`), `autonomy` (`measure_type`, `definition`,
`levels` if ordinal), `social_engagement` (`measure_type`, `definition`, `components`). The authoritative field table is
generated by `schema.schema_markdown()`.

## 5. Synthetic fixture

`data/synthetic/synthetic_fixture.csv` and `.meta.yaml`: 240 fictional borrowers, seed 20241225. Deliberate edge
cases: about 5% zero baseline income, missing values in four fields, repeated households, and four boundary ages
(29, 30, 45, 46). Coefficients in the generator are arbitrary and are not tuned to the paper's percentages.
